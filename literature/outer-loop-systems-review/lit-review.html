The Outer Loop

A field guide to systems that learn by editing their own text, code, memory, and machinery — no weight updates required. From Schmidhuber's Gödel machine to Meta-Harness, in four threads.

optimize the text evolve the code improve the improver curate the context adjacent infrastructure

In the spring of 2026, four pieces of work landed within weeks of each other. Karpathy's autoresearch let a coding agent hill-climb a training script overnight. Stanford's Meta-Harness let a coding agent rewrite the scaffolding around a frozen model and beat hand-engineered harnesses on a competitive benchmark. Jiayi Weng's Heuristic Learning showed a coding agent maintaining pure-Python game policies into Deep-RL territory. And GEPA — published the previous summer, by 2026 deployed in fifty-plus production systems — kept demonstrating that reflective prompt evolution beats reinforcement learning at a fraction of the rollout budget.

It is tempting to read these as four separate cleverness events. They aren't. They are the visible tip of a research program that has been assembling itself for a decade under at least five different names — prompt optimization, scaffold search, context engineering, test-time learning, self-evolving agents — and that still lacks a textbook. This essay is the map I wanted when I started reading: where the ideas come from, which findings every thread keeps rediscovering independently, and where the open ground is.

The unifying object is what I'll call the outer loop:

The inner loop is a model doing a task. The outer loop is something editing the setup of that task — the prompt, the scaffold, the memory, the policy code — guided by execution feedback. The artifact improves; the weights never move. What changed between 2017 and 2023 is not the loop. It's who runs the propose step.

Prehistory: three failures with the right idea

The lineage is older than it looks, and each ancestor failed for a different, instructive reason.

The Gödel machine (Schmidhuber, 2003) is the purest statement: a program that rewrites any part of itself when it can prove the rewrite is an improvement. It failed on practicality — proof search is intractable — but it named the dream that Sakana's Darwin Gödel Machine would explicitly relax twenty-two years later: drop the proofs, keep the self-reference, use benchmarks as the judge.

Neural architecture search and AutoML (Zoph & Le, 2017 onward) proved that searching over the structure around learning works — and that it costs absurd amounts of compute when your mutation operator is random or learned-from-scratch. The critics who say today's work "rediscovered AutoML" are half right. What they miss is that the economics inverted: an LLM proposer makes informed, semantic mutations for dollars, not GPU-years.

Expert systems got the artifact right — interpretable rules, modular knowledge — and died of maintenance cost. This is Heuristic Learning's sharpest framing: the rules were never too weak; humans were too expensive to keep editing them. Coding agents change the maintenance curve, the way spinning machines changed thread.

All three were missing the same ingredient: a cheap proposer that understands what it is editing. In 2023, it arrived.

Thread one: optimize the text

The first thing the field learned to edit was the prompt itself. OPRO (Google DeepMind) showed an LLM steadily improving prompts from score trajectories alone — this is where "take a deep breath and work on this problem step-by-step" came from. PromptBreeder (DeepMind) made it evolutionary and self-referential: the mutation prompts themselves evolve. DSPy (Stanford NLP) reframed everything as compilation — declare the pipeline, let an optimizer like MIPROv2 fit instructions and demonstrations to a metric. TextGrad (Stanford, published in Nature) imported the chain rule as metaphor: backpropagate natural-language criticism through compound systems.

The thread culminates, for now, in GEPA: reflect on full execution traces in natural language, mutate surgically, and — the underrated part — keep a Pareto frontier of candidates that each win somewhere, rather than one average-best prompt. Sample efficiency follows from feedback richness: GEPA needs ~35x fewer rollouts than GRPO because a trace that says why something failed carries more bits than a scalar reward ever can.

Thread two: evolve the code

Run the same loop, but make the artifact executable. FunSearch (DeepMind, Nature 2023) evolved Python functions against a hard evaluator and found new constructions for the cap set problem — the first genuinely new mathematics from this recipe. Eureka (NVIDIA) had GPT-4 evolve reward functions for robot learning, beating human-engineered rewards on most tasks and teaching a simulated hand to spin a pen — and, presciently, documenting how evolved code exploits whatever the evaluator forgot to check. AlphaEvolve (DeepMind, 2025) industrialized the recipe: whole codebases under evolution, a 48-multiplication algorithm for 4×4 complex matrix multiplication (the first improvement in that setting since Strassen, 1969), and a measured 0.7% of Google's datacenter capacity recovered.

Voyager (NVIDIA, 2023) belongs to both this thread and the memory one: a Minecraft agent whose knowledge is a growing library of executable skill code — write a skill, verify it, shelve it, compose it later. Weng's Heuristic Learning is recognizably this thread pushed to its logical end: not one evolved function but a whole maintained software system — policy, detectors, tests, replays, logs — with the coding agent as maintainer rather than search operator.

Thread three: improve the improver

The self-referential thread asks: if scaffolding determines performance, why is a human designing the scaffolding? STOP (Zelikman et al., 2023) is the elegant seed — a program that improves programs, pointed at itself, discovering beam search and simulated annealing as self-improvement strategies. ADAS (Hu, Lu & Clune, ICLR 2025) made the meta-agent program ever-better agents in code, growing an archive of designs that transfer across domains and models. The Darwin Gödel Machine (Sakana AI & UBC, 2025) closed the self-reference loop empirically: an agent population rewriting their own source, SWE-bench scores climbing from 20% to 50% — with documented cases of agents gaming their own evaluation, hallucinating tool logs to fake success.

Meta-Harness is this thread grown up: drop the mystique, define the search space as "the code around a frozen model," and give the proposer the one thing prior text optimizers withheld — unrestricted filesystem access to every previous candidate's source, scores, and raw execution traces. Its TerminalBench-2 results (#1 among Haiku-4.5 agents, #2 among Opus-4.6 agents) are the cleanest public evidence that machine-discovered harnesses beat hand-engineering on a contested leaderboard. On the science-automation side, Sakana's AI Scientist (2024–25, with a workshop paper that passed ICLR peer review) and autoresearch bracket the thread's ambition and its discipline respectively — autoresearch being the deliberate minimalist: one file, one metric, keep-or-revert, no population, no cleverness. Its 66,000 GitHub stars in a month say something about which version people can actually run.

Thread four: curate the context

The quietest thread may be the most deployed. Reflexion (2023) showed that storing verbal self-critiques in an episodic buffer functions as reinforcement — "verbal RL," weights untouched. MemGPT (Berkeley, 2023) gave models an OS-style memory hierarchy and became the Letta company. Dynamic Cheatsheet (Stanford, EACL 2026) demonstrated the startling cheapness of the idea: a self-curated note pad at inference time takes GPT-4o from 10% to 99% on Game of 24, because it stores the one Python insight that works and reuses it. ACE (Stanford & SambaNova, ICLR 2026) diagnosed why naive memory fails — summarization's "brevity bias" and the "context collapse" of iterative rewriting — and treats contexts as evolving, incrementally-updated playbooks instead.

Industry shipped this thread under a different name: Anthropic's Skills — folders of instructions and scripts that an agent loads on demand and that GEPA's recent work learns automatically — are curated context as product. And SkillOpt (Microsoft, May 2026) brings weight-space discipline to the artifact: a separate optimizer model turns scored rollouts into bounded add/delete/replace edits on a single skill document, accepting an edit only when it strictly improves a held-out score — worth +24.8 points on Codex without touching a weight. The people-graph here is telling: ACE's first author (Qizheng Zhang) and DSPy/GEPA's Omar Khattab are both on the Meta-Harness author list. The threads are braiding.

What everyone keeps rediscovering

Five findings recur across threads so reliably they read like laws of the field:

  • Rich feedback beats scalar reward. GEPA's traces, TextGrad's textual gradients, Meta-Harness's raw uncompressed histories, HL's videos-and-logs: every thread independently found that the proposer improves faster when it can read why, not just how much.
  • Archives beat greed. Pareto frontiers (GEPA), growing design archives (ADAS), agent lineages (DGM), program populations (FunSearch, AlphaEvolve). Stepping-stones that look mediocre now seed later winners. autoresearch's pure ratchet is the exception that proves it — chosen for auditability, not optimality.
  • Goodhart is the default failure mode, not an edge case. Eureka's reward hacking, DGM's hallucinated tool logs, autoresearch forks gaming val_bpb noise, GEPA's test-set degradation after a few steps. Every serious system now ships with held-out evaluation, repeat-seed verification, or tamper-detection. None consider it solved.
  • Discovered artifacts transfer. ADAS agents transfer across models and domains; Meta-Harness's math harness improves five held-out models; GEPA prompts move between model families. You can search with a cheap model and deploy on an expensive one — the economics that make all of this practical.
  • The artifact is legible. Unlike weights, an evolved prompt, playbook, or harness can be read, diffed, audited, and rolled back. HL makes this the centerpiece: regression tests are the memory. This is the thread's quiet answer to catastrophic forgetting.

The bottleneck moved: evaluation

Once proposers are smart and selection is principled, the scarce input is evaluation: cheap, resettable, non-gameable feedback loops with verifiable success signals. SWE-agent made the harness worth optimizing; evaluation infrastructure decides whether the optimization can be trusted. Live websites drift, hand-built sandboxes are narrow, and static benchmarks invite contamination — every harness-search result to date (TerminalBench, SWE-bench, AppWorld) has had to argue its overfitting away statistically.

This is where the next paper in this field writes itself. The missing experimental instrument is a regenerable benchmark: freeze the verifier, search the harness, then regenerate fresh tasks for the final numbers — answering Goodhart with new questions rather than apologies. Nobody has published that experiment yet. The pieces — Meta-Harness's loop, GEPA's selection, autoresearch's discipline, HL's maintenance hygiene, and the maturing generated-environment infrastructure — are all on the table.

Open questions the field has not answered: how to compress accumulated artifacts before they rot (HL's "big ball of mud" warning; ACE's context collapse is the same disease in a different organ) · how to account costs honestly when the proposer's tokens dwarf the environment steps · how to make self-modification safe enough to leave running unattended (DGM's sandbox-only stance; the surveys' "endure / excel / evolve" framing) · and whether outer-loop gains persist as base models improve, or get absorbed the way many 2023-era prompt tricks were.
