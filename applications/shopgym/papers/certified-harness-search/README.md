# Certified Harness Search for Web Agents

[`index.html`](index.html) is the manuscript-style HTML draft for applying a
gated, archive-based outer loop to ShopGym e-commerce tasks.

The current tables and plots referenced by the project were produced by the
seeded mock/calibrated environment in `applications/shopgym/src/` and
`applications/shopgym/results/`. They test the proposed protocol and software.
The paper's empirical claims require replacement or confirmation with live
ShopGym runs under frozen task splits, models, budgets, and held-out shops.

The supporting early concepts are indexed in [`../research-notes/`](../research-notes/).
