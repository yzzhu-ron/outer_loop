# ShopGym paper records

- [`shopgym-submission/`](shopgym-submission/) collects the ShopGym submission
  sources, analysis, and follow-up proposal.
- [`certified-harness-search/`](certified-harness-search/) is the standalone
  harness-search manuscript draft.
- [`research-notes/`](research-notes/) preserves the earlier paper concepts that
  led to the harness-search draft.

All three records belong to the ShopGym application because their task model,
evidence, and claims depend on ShopGym.
