# ShopGym harness-search concepts

These pages preserve three early directions developed before the standalone
harness-search draft:

1. [`concepts/idea-c1-harness-taxonomy.html`](concepts/idea-c1-harness-taxonomy.html)
   defines a taxonomy and measurement program for harness components.
2. [`concepts/idea-c2-gamma-measurement.html`](concepts/idea-c2-gamma-measurement.html)
   proposes measuring how much execution traces improve harness proposals.
3. [`concepts/idea-c3-shopgym-harness-search.html`](concepts/idea-c3-shopgym-harness-search.html)
   assembles the full ShopGym outer-loop experiment.

They are research notes, not separate submissions. The integrated draft is in
[`../certified-harness-search/`](../certified-harness-search/).
