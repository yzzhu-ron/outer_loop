Harness-Search for ShopGym:
Outer Loop Applied to E-Commerce CUA

Apply the gated ratchet outer loop to search for the optimal CUA harness on e-commerce web tasks. This is the paper that closes the loop between the outer-loop theory and the ShopGym benchmark.

🔥 Hot Web Agents Empirical Application

Why This Paper Needs to Exist

The ShopGym paper (arxiv 2605.16116) introduces a rigorous e-commerce benchmark and establishes CUA agent baselines. The outer-loop theory paper proves that frozen-weight improvement via harness search is possible and gives certified convergence conditions. But neither paper does both at once: ShopGym doesn't search harnesses, and the theory doesn't have empirical results on real web tasks.

This paper is the bridge. It:

  • Instantiates the outer loop concretely on ShopGym e-commerce tasks
  • Uses the gated ratchet (not naive ratchet) to avoid the ratchet illusion during harness selection
  • Measures γ for web-agent traces (the first such measurement in a real browser environment)
  • Demonstrates that archive search beats greedy on the deceptive harness landscapes that arise in multi-step checkout flows
The Core Claim

The outer loop, applied correctly with a gated ratchet selector, can improve a frozen CUA agent's task completion rate on ShopGym by >15 pp — without any weight update, prompt engineering, or fine-tuning.

The Deceptive Checkout Landscape

This is the key insight that makes the paper non-trivial. E-commerce web tasks have a specific landscape structure that is inherently deceptive for outer-loop search:

Why checkout tasks are deceptive

Consider a 4-step task: search → select → add-to-cart → checkout → confirm. A harness that improves performance at step 2 (select) may reduce performance at step 5 (confirm) by over-committing to specific product variants early. A greedy outer loop selects harnesses that look better after step 2 — but globally worse.

Concretely: a harness using structured extraction as observation modality excels at product selection (high local score) but fails at checkout confirmation because it loses the visual layout of the payment form. A hybrid (ax_tree + screenshot) harness is globally better but looks worse at the product-selection checkpoint.

This is exactly the deception pattern (Defn 5.2) where the outer loop needs an archive, not a greedy selector.

Three Core Contributions

  • 1
    Gated ratchet selector for harness search. The ratchet illusion (§5 of main paper) applies directly to harness selection: a harness that looks better on N=5 evaluation episodes could be noise. We apply the gated ratchet with N=85 repeats (Wilson-interval certified) to avoid accepting noisy harness improvements. First demonstration of certified harness selection in a real browser environment.
  • 2
    First empirical γ measurement for web-agent traces. We measure γ — the trace-conditioning improvement for harness proposals — on ShopGym episodes. Web-agent traces are multi-modal (DOM events, screenshots, network logs) and long (100–2000 steps). Does γ remain high when traces are this noisy? Which trace subsections carry the most γ signal (error states vs. successful intermediate steps)?
  • 3
    Archive beats greedy on checkout tasks, not on search tasks. We demonstrate the landscape-topology prediction empirically: single-page product search has a smooth harness landscape (greedy works); multi-step checkout has a deceptive landscape (requires archive). This is the first empirical confirmation of Thm 5.4 in a real application domain.

Theory Applied — Thm 6.1 in the ShopGym Setting

Theorem 6.1 (applied to ShopGym harness search)

With a gated ratchet selector, to certifiably improve task completion rate from q₀ to q₀ + Δ with probability ≥ 1−δ, the total number of ShopGym episodes needed is at most:

T_total ≤ O((σ²/Δ²) · ln(B/δ) · ln(1/δ) / (γ · q₀))

where σ² = q₀(1−q₀) (Bernoulli task completion), B = harness archive size, δ = failure probability, γ = measured trace-conditioning boost, q₀ = baseline task completion rate.

Plugging in ShopGym numbers: q₀ ≈ 0.35 (Claude 3.5 Sonnet baseline on checkout tasks), Δ = 0.15 (target improvement), δ = 0.05, B = 50 archive entries. If γ ≈ 10 (conservative estimate), T_total ≤ ~3,000 episodes. That's ~$300 in API costs and 2 days of wall-clock time.

Key Question

Is γ ≥ 10 for web-agent traces? If yes, the outer loop is practical. If γ ≈ 1–2, traces barely help and the approach requires either better trace formatting or a different feedback design (→ Idea D4: Feedback Engineering).

Experimental Design

Task types used (stratified across ShopGym categories):

product_search add_to_cart multi_item_cart checkout_single_item checkout_with_coupon checkout_with_address_entry order_tracking product_comparison
Phase 1 · Baseline + γ

Measure γ for web-agent traces

Protocol: Run 200 baseline episodes (no outer loop) per task type. Collect full traces. Condition harness proposer on traces; measure acceptance rate uplift vs. unconditioned proposer. Compute γ̂ with Wilson CI.

Output: γ per task type table. Expected: checkout tasks have higher γ (richer error traces) than product search (errors are sparse).

Phase 2 · Greedy vs. Archive

Topology characterization

Protocol: On each task type, run 10 outer-loop steps with (a) greedy-ratchet, (b) archive-ratchet (B=20), (c) random search baseline. Measure final task completion rate and convergence speed.

Prediction: Archive > greedy for checkout tasks (deceptive); greedy ≈ archive for product search (smooth).

Phase 3 · Ratchet Illusion Check

Demonstrate gated vs. naive ratchet

Protocol: Run naive ratchet (N=5 eval episodes per step) vs. gated ratchet (N=85). Count how many steps the naive ratchet "accepts" a harness that is actually worse (ratchet illusion events). Show the gated ratchet's certified monotone improvement.

Expected: naive ratchet has ~30% illusion events (consistent with §5 main paper at N=5); gated has <5%.

Phase 4 · Final Comparison

vs. ShopGym baselines

Protocol: Compare outer-loop–optimized harness (best from Phase 2) against (a) original ShopGym CUA baseline, (b) human-engineered best harness from ShopGym paper, (c) prompt-engineering baseline (same budget as outer loop, spent on prompt iteration).

Claim: outer-loop harness search matches or exceeds the human-engineered baseline with comparable compute budget, and certifiably so.

How This Closes the Loop with ShopGym

The ShopGym paper (arxiv 2605.16116) makes three design choices that this paper validates or challenges theoretically:

ShopGym design choice 1: Fixed harness architecture

ShopGym evaluates agents with fixed harness configurations. This paper shows that harness configuration is itself searchable (γ > 1) and that the outer loop can systematically improve it. Recommendation back to ShopGym: include harness-search as an evaluation axis alongside model capability.

ShopGym design choice 2: Task completion as sole metric

Outer-loop harness search requires N=85 repeats of each episode for the gated ratchet certificate. At scale, this motivates ShopGym to expose a fast-evaluation mode (abbreviated episode with partial-completion scoring) to make outer-loop search tractable. This is a concrete design feedback from the theory to the benchmark.

ShopGym design choice 3: Checkout as the hardest task class

This paper confirms checkout is hardest (lowest q₀) but also shows it has the highest γ — making it the most searchable. The outer loop's advantage is largest precisely where ShopGym performance is lowest. This is a striking alignment between the theoretical prediction and the benchmark structure.

The Paper in One Sentence

By running a gated-ratchet archive search over CUA harness configurations on ShopGym, we achieve certified improvement over the human-engineered baseline on multi-step checkout tasks — the first demonstration that the outer loop works in a real browser environment.
