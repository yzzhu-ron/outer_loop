What is γ and Why Does It Matter?

Definition — Trace-conditioning improvement (γ)

For a proposer Q and evaluator F, γ is the multiplicative boost in proposer success probability when conditioned on execution traces vs. conditioned only on the task description:

γ = Q(F(a*) = 1 | τ₁…τₙ) / Q(F(a*) = 1 | task)

where τ₁…τₙ are execution traces from previous proposals. γ > 1 means traces help; γ = 1 means they don't (scalar reward is sufficient); γ ≫ 1 means traces are exponentially more valuable than scalar (consistent with GEPA 35× speedup).

The outer-loop theory (main paper, Prop 3.5 and Thm 6.1) shows that the total budget to certifiably reach a good artifact scales as O(1 / (γ q₀)). Every factor of 2 in γ halves the compute needed. Yet no paper has ever measured γ directly — it is always assumed to be "large enough." This paper measures it.

Pre-Registered Protocol (Appendix I)

The following protocol was written into the ICLR 2027 submission before execution. It cannot be modified post-hoc. The paper reports this protocol verbatim and then presents results.

Task class — Buggy program repair

120 Python programs, each with a single latent bug. Bugs are stratified across 4 types (off-by-one, type error, logic inversion, API misuse — 30 each). Each program has a deterministic unit-test oracle (binary pass/fail). A "proposal" is a patch (diff) to the program; a proposer is an LLM that generates patches given task + optional feedback.

Execution procedure (per condition)

  • Sample 70 proposals from the proposer conditioned on task + feedback mode. Proposals are independent (no selection within this step).
  • Run oracle evaluator (deterministic unit tests). Record binary F(aᵢ) ∈ {0,1} for each proposal i.
  • Estimate pass rate p̂ = Σ F(aᵢ)/70 with Wilson 95% confidence interval.
  • Compute γ̂ = p̂_condition / p̂_C0. Propagate Wilson CIs through the ratio using delta method.
  • Report: point estimate γ̂, 95% CI, p-value for H₀: γ = 1 (two-sided binomial test).

Wilson confidence interval (the mandatory CI formula)

For n = 70 trials and k successes, the Wilson interval is:

p̃ = (k + z²/2) / (n + z²)
margin = z × √(p̃(1−p̃) / (n + z²))
CI = [p̃ − margin, p̃ + margin]   (z = 1.96 for 95%)

Use Wilson (not Wald) because n=70 is small enough that Wald intervals undercover near p=0 or p=1. This is the same correction motivated by the ratchet-illusion result in §5.

Expected Results and Theoretical Predictions

The feedback-channel theorem (Thm 4.2) predicts γ_trace ≫ γ_scalar — specifically, the gap should grow exponentially with the number of informative bits L in a trace. For buggy program repair:

Theoretical prediction for buggy program repair

A stack trace for an off-by-one error carries ~L ≈ 8–12 bits (line number, variable values, test assertion). Thm 4.2 predicts:

γ_trace / γ_scalar ≥ 2^L ≈ 256–4096×

This is consistent with GEPA's empirically observed 35× speedup (which uses partial traces, not full ones). Full traces should be larger. The measurement paper tests whether the bound is tight or loose.

Key Question

Is γ_trace / γ_scalar consistent with 2^L (tight bound)? Does γ vary significantly across bug types? If API-misuse bugs have much higher γ than off-by-one bugs, the outer loop should prioritize high-γ task classes.

Paper Contributions

01
First empirical γ table

Measured γ values for 3 feedback modalities × 3 model sizes × 4 bug types. The field has no such table today.

02
Tightness of Thm 4.2

Is the 2^L bound tight or loose? The answer tells theorists whether to seek a tighter bound or practitioners whether the theory is already actionable.

03
γ as a pre-experiment diagnostic

Procedure for any team to measure γ on their task before committing outer-loop compute budget. If γ ≈ 1, traces are not helping; switch feedback format.

04
Feedback format ranking

Trace ≫ distance signal ≫ scalar, empirically confirmed. Gives practitioners a clear priority order.

05
Model scaling laws for γ

Does γ scale with model size (capability) or stay flat? Has implications for which model to use as the proposer in an outer loop.

06
Grounds the harness taxonomy

The γ measurement protocol from this paper is the same one used in Idea C1 (per-dimension harness searchability). This is the foundational method paper.
