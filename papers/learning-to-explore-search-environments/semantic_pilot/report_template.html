A pinned local Qwen3 4B model generates the semantic variants; BM25 and a pinned MiniLM encoder search the full released corpora.

Each target corpus is held out from source fitting. The other two supply 128 router-training, 32 calibration and 32 selector-utility queries each. Onboarding sees sampled documents and selected probe outcomes, but no real target queries or labels. The same numerical profile and frozen router are shared by all four selectors.

How much learning signal does the selector receive?

Thousands of training rows can reuse only 64 unique source utility queries. These are not thousands of independent tasks. A one-step label is nonzero only when one extra probe changes a router decision and that change affects measured source utility.

@@SELECTOR_SIGNAL@@

A zero estimated one-step value need not imply that a diverse batch has zero value: complementary probes can be individually unhelpful. The exact XOR example in the theory note demonstrates this stopping trap.

Could this router respond to any allowed probe history?

For budget B, every shrunk profile feature lies between −B/(B+4) and B/(B+4). Multiplying that range by each correction head's coefficient L1 norm bounds how far its score can move; the original action's correction is exactly zero. If a query's winning margin exceeds the combined winner/challenger bounds, its action cannot change in this score/bound model of the frozen router. This conservative audit uses query features and source-trained coefficients, without target utility labels.

@@SENSITIVITY@@

The bound may substantially overestimate possible movement because feature extremes need not occur together. Numerical comparisons include rounding slack; this is not formally verified interval arithmetic. Uncertified queries are only potentially changeable, not guaranteed to benefit.

Does the proxy measure the right thing?

A generated question has a known source document, making rediscovery cheap to score. Real users can have different information needs, and other retrieved documents can also answer the generated question. Known-document reciprocal rank is therefore a proxy endpoint, not complete relevance supervision.

The fixed audit also found scope differences between some direct and indirect questions. Comparing these families measures the constructed probes; it does not isolate a causal effect of paraphrasing or difficulty alone.

A post-result support check found that all probes contain more than eight tokens, while 35/150 SciFact, 51/150 FiQA and 61/65 NFCorpus test queries fall in the short-query buckets. Default audits check the observed bucket union; explicitly declaring all four expected buckets reveals this missing coverage. Among strict single-query pairs, 78.7% have equal known-target ranks and 69.2% rank the target first on both sides. The technical audit records the denominators and limitations.

The uniform policy mixture has worst-case regret (1 + ε) / 3. A uniform prior over the three worlds certifies the same lower bound. The pairwise statistic is only ε, so it can approach zero while unresolved decision risk stays near one third.

More generally, the minimax regret radius is zero exactly when all compatible environments share an optimal policy. A worst-case certificate needs at most as many worlds as there are policies. These are consequences of standard finite minimax duality; we are not claiming the underlying mathematics as new.

What additional assumptions connect observations to decisions?

In the linear model z = Vθ and action contrasts g = Wθ + b, recovering contrasts from noiseless probes requires ker(V) ⊆ ker(W) on an admissible parameter domain with interior. With g approximately Cz + b, a regret upper bound separates alignment error, reconstruction instability and sampling noise. Repetition reduces only its sampling term; this is not an exact regret decomposition or a positive lower bound.

The bound includes the zero-contrast reference action and requires a frozen design before the noise samples used in concentration. It is not a confidence guarantee for our adaptive empirical selector. Noisy target observations cannot certify source-to-target alignment without additional assumptions.

The exact examples also show a nuisance probe with more environment information but no decision value, and two complementary probes whose individual one-step values are zero. These constructions explain failure modes; they are not retrieval measurements.

Charge the experiment before claiming savings

Every positive-budget selector pays for inspecting 16 documents and generating its entire candidate pool. A paired probe costs two searches, or three for decomposition. A generated serving action pays the full shared rewrite response. Cached experiment outcomes never make deployment interactions free.

A small tool people can use now

searchprobe is an installable Python package with no runtime dependencies. It accepts logs from any search API. A preflight audit catches identical query strings, token-bag collisions and missing coverage; observed logs add ties, rank-one saturation, floor effects and cost consistency checks.

python -m pip install ./packages/searchprobe
searchprobe audit probes.jsonl --output report.json
searchprobe decision-audit source-model.json --output decision.json
searchprobe response-audit score-bounds.json --output response.json

The second command requires an explicit utility matrix, source provenance, task weighting and assumptions. It returns the exact decision radius, an attaining policy mixture, and a sparse dual witness. Every report says target_regret_guarantee: false. A clean probe audit and a small source-model radius cannot establish transfer to a new corpus.

The six measured source-model audits use only router-training queries from each fold's two source corpora. Their oracle picks one fixed query action per source world. Each saved model is a reusable input to the same command; exact arithmetic certifies optimization of those supplied means, without eliminating sampling uncertainty.

The third command checks a different prerequisite: can bounded score corrections change any router decision? It uses exact rational arithmetic, honors tie rules, and lists possible alternative winners. Six measured router audits reproduce the original pipeline's 100% unchanged result at budget 32, with no target relevance labels. The exported score model runs through the same public command as the synthetic example. The certificate is conditional on the supplied bounds; it does not verify the numerical implementation or prove that changing an action would help.

The package is available from this branch; it has not been published to a package registry. Its finite exact solver is intentionally bounded to small models. The source code, examples and tests make it useful without a paid API or proprietary backend.
